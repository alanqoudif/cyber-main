# 🎮 Interactive Story Mode - اللعبة التفاعلية

## 🎉 المميزات الجديدة

تم تطوير Story Mode لتصبح **لعبة تفاعلية حقيقية** بدلاً من مجرد مشاهدة قصة!

---

## ✨ ما الجديد؟

### 1. **نظام الاختيارات التفاعلية**
- في كل مشهد رئيسي، اللاعب يواجه قرار مهم
- 2-3 خيارات متاحة للاختيار من بينها
- كل اختيار له نتيجة وعواقب مباشرة

### 2. **نظام النقاط**
- اللاعب يكسب نقاط على الاختيارات الصحيحة
- النقاط تتراكم عبر جميع السيناريوهات
- عرض مباشر للنقاط مع رموز تعبيرية:
  - 🏆 +50 نقطة: خبير أمني
  - ⭐ 30-49 نقطة: أداء ممتاز
  - 🎯 10-29 نقطة: بداية جيدة
  - 🎮 0-9 نقاط: ابدأ اللعب

### 3. **Feedback فوري**
- رد فعل مباشر على كل اختيار (✅ أو ❌)
- شرح للعواقب المباشرة للاختيار
- تأثيرات بصرية (أخضر للصح، أحمر للخطأ)
- Animation للاختيار (scale, shadow, bounce)

### 4. **تأثيرات بصرية متقدمة**
- الاختيارات تتحول إلى أخضر/أحمر عند الضغط
- Hover effects على الاختيارات
- Disable للخيارات الأخرى بعد الاختيار
- Bounce animation على الـ emoji
- Scale animation على البطاقة المختارة

### نوع الاختيار
```typescript
type StoryChoice = {
  id: string
  text: LocaleValue
  isCorrect: boolean
  feedback: LocaleValue
  consequence: LocaleValue
  nextScene?: string // للمستقبل: تفرع القصة
```

## 🎯 كيفية اللعب

### 1. **ابدأ القصة**
- اختر سيناريو من الثلاثة
- اضغط "ابدأ القصة"
- شغّل الموسيقى (اختياري)

### 2. **شاهد المشهد**
- اقرأ الحوار والوصف
- انتظر حتى يظهر قسم "🎮 شو بتسوي؟"

### 3. **اختار بحكمة**
- اقرأ الخيارات بعناية
- اختار واحد من الخيارات
- شاهد النتيجة الفورية (✅/❌)

### 4. **اكسب النقاط**
- الاختيارات الصحيحة تعطيك نقاط
- الاختيارات الخاطئة لا تعطي نقاط
- النقاط تتراكم عبر جميع المشاهد

### 5. **انتقل للمشهد التالي**
- اضغط "المشهد التالي" بعد الاختيار
- المشاهد غير التفاعلية (3 و 4) تكمل القصة

### 6. **أكمل السيناريو**
- اقرأ الدرس المستفاد في النهاية
- جرب سيناريو آخر لمزيد من النقاط!

## 🎓 التعلم من خلال اللعب

### لماذا Interactive Mode أفضل؟

1. **Active Learning**
   - اللاعب يتخذ قرارات حقيقية
   - التعلم بالتجربة والخطأ

2. **Immediate Feedback**
   - معرفة النتيجة فوراً
   - فهم لماذا هذا الاختيار صح/خطأ

3. **Gamification**
   - النقاط تحفّز اللاعب
   - المنافسة (مع النفس أو الآخرين)

4. **Consequence Awareness**
   - كل اختيار له عواقب واضحة
   - فهم التأثير الحقيقي للقرارات

5. **No Pressure**
   - لا يوجد "Game Over"
   - يمكن إعادة المحاولة
   - التعلم بدون ضغط

```typescript
{
  id: 'new-scenario',
  // ... بقية الخصائص ...
  scenes: [
    {
      id: 'scene-1',
      // ... خصائص المشهد ...
      needsChoice: true,
      choices: [
        {
          id: 'choice-1',
          text: { en: 'Option 1', ar: 'الخيار 1' },
          isCorrect: true,
          feedback: { en: '✅ Great!', ar: '✅ ممتاز!' },
          consequence: { en: 'You did well', ar: 'أحسنت' },
          points: 10
        },
        // المزيد من الخيارات...
      ]
    }
  ]
}
```

### إضافة مشهد بدون choices:
```typescript
{
  id: 'scene-4',
  // ... خصائص المشهد ...
  needsChoice: false
  // لا تضيف choices
}
```
